# Rencana Pengembangan Laravel Stisla (`plan-2026-11-21`)

Dokumen ini merangkum ide dan peta jalan (*roadmap*) pengembangan lanjutan untuk template **Laravel Stisla Multi-Vertical Starter Kit** (`online-shop`, `spp-payment`, `news`, `lp-compro-workers`) berdasarkan fondasi fitur yang sudah terbangun saat ini.

---

## Ringkasan Fondasi Saat Ini
- **Core Admin Boilerplate (`routes/stisla-web.php`)**:
  - Multi-template (`stisla` & `spark-admin`) dan multi-vertical app switcher (`config/stisla.php`).
  - Autentikasi lengkap (Login, Register + Aktivasi Email, Forgot/Reset Password, Google OAuth).
  - RBAC (Users, Roles, Permissions) dengan fitur standar: *Duplicate, Export Excel, Export PDF, Import + Template*.
  - Dynamic Menu Management, Dynamic Settings per grup, Profile Management.
  - Modul Pendukung: Ticket Support, Announcements, App Notifications, Internal Chat, Database Backups, Log Request Viewer, Laravel Log Viewer, Database Table Explorer.
  - Dukungan penuh lokalisasi dwibahasa (`lang/id.json` & `lang/en.json`) di seluruh halaman Admin dan Customer.
- **Vertical E-Commerce (`online-shop`)**:
  - Storefront berbasis Mantu + Dashboard E-Commerce di Admin (`/app/ecommerce/dashboard`).
  - Katalog: Products, Product Categories, Footer Product Categories, Brands, Vendors, Sizes, Colors, Banners, Reviews.
  - Konten & Layanan: Store Services, E-Commerce FAQs, Testimonials, Our Teams, Blogs & Nested Comments.
  - Transaksi: Cart, Wishlist, Compare, Checkout, Shipping Methods (dengan input resi + notifikasi email), Payment Methods & Payment Banks (Transfer Manual, QRIS, Upload Bukti Bayar, Cetak Bukti Pesanan A4).
  - Referensi Wilayah Indonesia: Tabel & model `Province` (34 provinsi) dan `Regency` (514 kota/kabupaten) dari `database/indonesia.sql` terintegrasi pada halaman registrasi customer.

## 1. Penyempurnaan Modul E-Commerce (`online-shop`)

### 1.1. Sistem Kupon / Voucher Diskon (`coupons`)
- **Konteks**: UI input kupon di `resources/views/ecommerce/pages/checkout.blade.php` serta kolom `coupon_code` dan `discount_amount` pada tabel `orders` (`app/Models/Order.php`) sudah tersedia.
- **Rencana Implementasi**:
  - [ ] Buat migrasi dan model `Coupon` (`code`, `type` [`fixed`/`percent`], `value`, `min_order_amount`, `max_discount_amount`, `usage_limit`, `used_count`, `starts_at`, `expires_at`, `is_active`).
  - [ ] Buat CRUD Admin `CouponController` lengkap dengan fitur *Duplicate, Export, Import*.
  - [ ] Buat endpoint AJAX `POST /ecommerce/checkout/apply-coupon` untuk memvalidasi kode kupon dan menghitung potongan harga secara langsung di halaman Checkout.
  - [ ] Validasi ulang kupon saat `CheckoutController@store` dan inkremen `used_count`.

### 1.2. Integrasi Wilayah (`Province` & `Regency`) ke `UserAddress`
- **Konteks**: Halaman `register.blade.php` sudah menggunakan dropdown berjenjang dari model `Province` dan `Regency`.
- **Rencana Implementasi**:
  - [ ] Gunakan dropdown berjenjang Provinsi (`state`) dan Kota/Kabupaten (`city`) dari database pada modal **Tambah Alamat** dan **Edit Alamat** di `resources/views/ecommerce/pages/address-list.blade.php`.
  - [ ] (Opsional) Impor tabel `districts` (Kecamatan) dari `database/indonesia.sql` untuk kelengkapan alamat pengiriman.

### 1.3. Halaman Lacak Pesanan (`track-order`) Dinamis
- **Konteks**: Halaman `resources/views/ecommerce/pages/track-order.blade.php` masih menggunakan data statis (`#5874`).
- **Rencana Implementasi**:
  - [ ] Tambahkan form pencarian berdasarkan `order_number` (dan verifikasi email/nomor telepon penerima).
  - [ ] Tampilkan progres langkah pesanan secara dinamis (`pending` → `processing` → `shipped` → `completed` / `cancelled`) beserta info ekspedisi, nomor resi, dan tautan bukti pengiriman.

### 1.4. Halaman Akun & Profil Customer di Storefront
- **Konteks**: Customer yang login sudah memiliki halaman *Address List*, *Order List*, dan *Ticket List*, namun belum memiliki halaman pengaturan profil di storefront.
- **Rencana Implementasi**:
  - [ ] Buat halaman `/ecommerce/account` untuk mengubah nama, foto/avatar, nomor telepon, alamat utama, serta form ubah kata sandi customer.
  - [ ] Tambahkan tautan **My Profile / Akun Saya** pada dropdown user di `resources/views/ecommerce/layouts/app-ecommerce.blade.php`.

### 1.5. Integrasi Payment Gateway Otomatis (Midtrans / Xendit / Duitku)
- **Konteks**: Pembayaran manual bank transfer & QRIS statis dengan unggah bukti bayar sudah berjalan.
- **Rencana Implementasi**:
  - [ ] Tambahkan konfigurasi kredensial Payment Gateway di `config/settings.php` (grup `payment_gateway`).
  - [ ] Tambahkan dukungan Snap/Invoice URL dan endpoint Webhook callback untuk memperbarui `payment_status` menjadi `paid` dan `status` menjadi `processing` secara otomatis.

## 2. Penguatan Core Template & Developer Experience (Boilerplate Value)

### 2.1. Artisan CRUD Generator (`php artisan stisla:make-crud {Model}`)
- **Konteks**: Seluruh modul admin memiliki pola arsitektur yang seragam.
- **Rencana Implementasi**:
  - [ ] Buat custom Artisan command untuk men-generate:
    - Model, Migration, Factory, Seeder.
    - Controller (dengan `index`, `create`, `store`, `show`, `edit`, `update`, `destroy`, `duplicate`, `export`, `exportPdf`, `template`, `import`).
    - Form Request Validation.
    - Views Stisla (`index`, `create`, `edit`, `show`) dengan komponen standar.
    - Entri permission & menu, serta key terjemahan dasar di `lang/en.json` & `lang/id.json`.

### 2.2. Dynamic Vertical & Template Switcher dari UI Admin / Demo Toolbar
- **Konteks**: `config/stisla.php` mendukung `menu_app` (`online-shop`, `spp-payment`, `news`, `lp-compro-workers`) dan `admin_template` (`stisla`, `spark-admin`).
- **Rencana Implementasi**:
  - [ ] Simpan preferensi `menu_app` dan `admin_template` di tabel `settings` (dengan fallback ke `config('stisla.*')`) atau session saat mode demo (`STISLA_IS_DEMO=t brue`).
  - [ ] Tambahkan floating switcher / dropdown di navbar admin agar pengguna atau calon klien dapat berpindah antar 4 vertikal aplikasi dalam 1 klik.

### 2.3. Audit Trail / Activity Log Model
- **Konteks**: Sudah ada `LogRequest` untuk mencatat HTTP request.
- **Rencana Implementasi**:
  - [ ] Buat modul `ActivityLog` untuk mencatat perubahan data sensitif (perubahan status pesanan, perubahan role/permission, perubahan settings) lengkap dengan nilai `before` dan `after`.

### 2.4. Two-Factor Authentication (2FA) & Manajemen Sesi Aktif
- **Konteks**: Tabel `sessions` sudah digunakan.
- **Rencana Implementasi**:
  - [ ] Tampilkan daftar perangkat/sesi aktif di halaman Profile (`resources/views/modules/profile/`) lengkap dengan tombol *Logout Other Devices*.
  - [ ] Tambahkan opsi 2FA via Email OTP atau Authenticator App (TOTP).

## 3. UX & Polish Storefront

### 3.1. Language Switcher (`ID` / `EN`) di Header Storefront Customer
- **Konteks**: Seluruh halaman customer sudah mendukung `__(...)` dan route `/lang/{locale}` sudah tersedia.
- **Rencana Implementasi**:
  - [ ] Tambahkan tombol/dropdown pemilih bahasa (`ID` | `EN`) di header desktop dan mobile menu pada `resources/views/ecommerce/layouts/app-ecommerce.blade.php`.

### 3.2. Quick View Modal Produk Dinamis
- **Konteks**: Modal `#quickview_modal` di `resources/views/ecommerce/layouts/app-ecommerce.blade.php` masih berisi data contoh statis.
- **Rencana Implementasi**:
  - [ ] Buat endpoint JSON ringan `GET /ecommerce/products/{product:slug}/quick-view` atau isi modal dari atribut data produk ketika tombol *Quick View* diklik, lengkap dengan tombol *Add To Cart* dan input kuantitas yang berfungsi.
